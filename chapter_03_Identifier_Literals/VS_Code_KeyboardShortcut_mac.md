# VS Code Default Keyboard Shortcuts — macOS

> Open the official cheat sheet anytime via **Help → Keyboard Shortcuts Reference** (`⌘K ⌘R`).
>
> Symbols: `⌘` Command · `⌥` Option/Alt · `⌃` Control · `⇧` Shift · `↩` Return · `⇥` Tab

## General

| Action | Shortcut |
|---|---|
| Show Command Palette | `⇧⌘P` / `F1` |
| Quick Open File | `⌘P` |
| New Window | `⇧⌘N` |
| Close Window | `⌘W` |
| User Settings | `⌘,` |
| Keyboard Shortcuts | `⌘K ⌘S` |

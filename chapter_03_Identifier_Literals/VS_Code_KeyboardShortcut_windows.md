# VS Code Default Keyboard Shortcuts — Windows

> Open the official cheat sheet anytime via **Help → Keyboard Shortcuts Reference** (`Ctrl+K Ctrl+R`).

## General

| Action | Shortcut |
|---|---|
| Show Command Palette | `Ctrl+Shift+P` / `F1` |
| Quick Open File | `Ctrl+P` |
| New Window | `Ctrl+Shift+N` |
| Close Window | `Ctrl+Shift+W` |
| User Settings | `Ctrl+,` |
| Keyboard Shortcuts | `Ctrl+K Ctrl+S` |
